# gsm_environment_allocation_profile_binding (Resource)

Manages the Binding of one Environment, which overrides the Project Binding. A Binding contains one or two revision targets; two targets use their relative `weight` values for traffic distribution. Targets reference `gsm_environment_allocation_profile` Profiles of the same Environment.

~> **Lifecycle:** Destroying this resource deletes the Environment Binding from GSM, so the Environment returns to the Project Binding. Without a Project Binding the Environment then fails to allocate, so keep a `gsm_project_allocation_profile_binding` unless the Environment should stop allocating. A Binding removed outside Terraform is planned for recreation.

~> **Owner identifiers:** `project` and `environment` accept a name or an ID, but Terraform compares the values as written. Use the same form in the configuration and in the import ID, and do not switch between a name and an ID later. A different form plans a replacement even for the same owner. A replacement deletes the Binding before it creates the Binding again, so in between the Environment falls back to the Project Binding.

## Example Usage

```terraform
resource "gsm_environment_allocation_profile_binding" "production" {
  project     = gsm_project.example.name
  environment = gsm_environment.production.name
  reason      = "send 10 percent of allocations to the candidate revision"

  # Keep a fixed revision while the managed profile advances to a candidate.
  targets {
    profile  = gsm_environment_allocation_profile.production.profile_name
    revision = 1
    weight   = 90
  }

  targets {
    profile  = gsm_environment_allocation_profile.production.profile_name
    revision = gsm_environment_allocation_profile.production.latest_revision
    weight   = 10
  }

  # Keep a Project fallback so Environments without their own Binding can allocate.
  depends_on = [gsm_project_allocation_profile_binding.default]
}
```

The example assumes the production Profile has advanced beyond revision `1`. Targets must reference distinct revisions. Adjust `90/10` to `10/90` to shift traffic, then remove the first target to complete the rollout. To roll back, keep only the first target with revision `1` and weight `100`; historical revisions stay immutable.

Weights are relative, so `9/1` and `90/10` express the same distribution. Changes replace the full target list. No separate promote or rollback resource is required.

## Import

Creating a Binding fails when its owner already has one, so import the existing Binding instead. Import a Binding with `gsm_environment_allocation_profile_binding/<project>/<environment>`:

```shell
terraform import gsm_environment_allocation_profile_binding.example gsm_environment_allocation_profile_binding/my-project/production
```
