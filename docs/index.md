# gsm Provider



## Example Usage

```terraform
provider "gsm" {
  address = "http://gsm.example.com"
  token   = "<jwt-token>"
}

resource "gsm_project" "test_project" {
  name = "test-project"
}
```

### Several GSM servers

One provider configuration reaches several GSM servers through `profile` blocks.

- With one `profile` block, every resource uses it.
- With more than one, each resource names its profile in the `profile` argument.
- `address` and `token` cannot be set together with `profile` blocks.
- An import ID takes the profile as a prefix: `<profile>::<id>`.

```terraform
provider "gsm" {
  profile {
    name    = "dev"
    address = "https://gsm-dev.example.com"
    token   = "<dev-jwt-token>"
  }

  profile {
    name    = "prod"
    address = "https://gsm.example.com"
    token   = "<prod-jwt-token>"
  }
}

resource "gsm_game_server_cluster_policy" "runner" {
  for_each = toset(["dev", "prod"])

  profile      = each.key
  cluster_name = "example-cluster"
  policy_name  = "runner"
  effect       = "allow"
  subjects     = ["urn:gsm::iam/user:runner@example.com"]
  objects      = ["urn:gsm::/cluster/gameserverclusters/example-cluster"]
  actions      = ["*_Get*"]
}
```

## Schema

### Optional

- `address` (String) Address of the GSM server. Defaults to the GSM_ADDR environment variable. Cannot be set together with profile blocks
- `profile` (Block Set) Named GSM server. With one profile block, every resource uses it. With more than one, each resource selects one with its profile argument. A profile is connected the first time a resource uses it (see [below for nested schema](#nestedblock--profile))
- `timeout_seconds` (Number) Timeout in seconds for the provider to connect to the GSM server
- `token` (String, Sensitive) Token for the GSM server. Defaults to the GSM_TOKEN environment variable. Cannot be set together with profile blocks
